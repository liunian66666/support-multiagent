# 长对话逐轮转写（旧路径臂 vs 新图臂）

用户原话逐轮全文；答复只截前 120 字（`answer_head`）+ 该轮墙钟，探针那一轮的答复全文在各自行内 `answer`。要更全的正文按 `thread` 回检查点/消息表取，但自建线程在采集收尾时会被清理——这份附录就是留档本身。
答复里的换行写成 ⏎（否则会把表格劈成半行），竖线已转义。
空格子分三种，别再误读成同一件事：`—（这一臂没落这个字段）` ＝旧数据缺字段；`（空答复）` ＝模型真的一个字都没回；`（空答复，HITL 中断）` ＝旧路径把这轮转成了待办审批（`success=true / is_interrupt=true`），客户侧没有任何文字，但会话照记。
