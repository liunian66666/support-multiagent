# 第三方网站接入演示（Python + SDK）

这是一个本地演示站点：Python 标准库服务在 `/get-token` 向客服系统申请短期**访客会话**，浏览器只拿客户令牌，管理密钥不会进入页面。访客可咨询 FAQ、转人工；查询个人订单需要接入商家真实登录态后由服务端签发客户令牌。

运行条件：客服系统已在 `http://localhost:8080` 启动，演示访客入口已开启，电脑装有 Python 3.10+。

```bash
cd thirdDemo
python main.py
```

打开 `http://localhost:8090`，右下角使用 `cs-chat.js` 加载客服浮窗。`CS_BASE_URL` 和 `DEMO_PORT` 可覆盖默认地址和端口。

此目录只展示访客体验。真实商家接入时，宿主后端必须先核验当前登录用户，再由受信任的身份接口签发绑定租户和客户的令牌；不要把管理员令牌或 `app_secret` 交给浏览器。真实订单 API 尚未接入，演示订单仅用于归属校验验收。
