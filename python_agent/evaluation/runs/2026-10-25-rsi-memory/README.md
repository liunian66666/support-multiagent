# RSI 与会话记忆对照实验（2026-10-25）

## 实验环境与变量

- 项目：`support-multiAgent`，演示租户 `t_demo`，网关→Python Business→Python Agent，MySQL 订单及 PostgreSQL 检查点。
- RSI：对既有四轮、每轮同一 50 题的真实链路结果，使用当前 `evaluation/score.py` 重新评分，并按 trace 核实经验是否真正命中。四轮原始 JSONL 在相邻 `2026-10-25-s10/`。这些数据采集于后续 FAQ 提示调整之前，且题目曾用于开发阶段，**不是新的独立留出集**。
- 会话记忆：同一个 `buyer1` 身份各签发两个独立会话。第一会话先问订单状态，再用无单号的指代句追问；第二会话只发送同一句追问。只使用只读订单查询，不执行退款/支付。每组用 trace 核验路由来源。
- 实验前后 `t_demo` 的经验策略均为版本 2、`off`；本次未发布或切换策略。

## RSI：历史四轮复算

| 轮次 | off | inject | 改善/回退 | inject 真实经验命中 |
|---|---:|---:|---:|---:|
| 1 | 30/50 | 32/50 | 5/3 | 20/50 |
| 2 | 32/50 | 32/50 | 4/4 | 12/50 |

off 自身从 30/50 变为 32/50；平均注入与关闭的字面规则分数差为 +2 个百分点，按题目重采样的描述性 95% 区间约为 **-6～+10 个百分点**，覆盖零。两轮经验命中数还不同：第二轮已停用部分经验，并添加注入护栏，不能当成同一个固定处理条件合并推断因果。命中子集第一轮 8→10/20、第二轮 4→6/12，但子集是按处理后 trace 划分，样本小且非随机；仅能作为线索。

RSI 的链路和审计能验证，**回答质量提升尚未证实**。字面 `required/forbidden` 分数也不等于答案忠实度。四轮端到端 p50 时延分别是 off 6480/6510 ms、inject 7884/6242 ms，没有一致的加速证据。完整汇总见 `rsi_trace_summary.json`，原始历史数据及此前误评分分析见相邻目录和 `docs/RSI_EVAL_AUDIT_2026-10-25.md`。

## 复算

在可用的 Python 环境中，将 `python_agent` 加入 `PYTHONPATH`，运行：

```text
python rsi_existing_analysis.py ../2026-10-25-s10 ../../gold_answers.jsonl
```

若在 Agent 容器内复算，设置 `SCORE_PATH` 指向当前 `score.py`，即可额外查询 PostgreSQL trace 并得到经验命中数。本目录保留了用于收集记忆原始数据的 `memory_ablation_live.py`。它从容器环境读取演示凭证，绝不将令牌写入结果文件。
