# 账户、账单与常见操作指引（t_demo 示例数据）

> 说明：本文档补齐「怎么查 X」这一类客服问法，对应知识库类目「操作指引」。
> 涉及具体菜单层级与页面名称的内容必须由业务方确认后替换；标有【待业务确认】的
> 文字不作为答复依据，不得向客户输出。客服侧只说明规则与边界，不代客户登录、
> 查询或导出任何账户资料。

## 账单与交易记录

- 账单、交易记录属于客户本人账户信息，客服无法代客户登录查看，也无法导出或发送账单文件。
- 客服看不到支付密码、完整支付账号等敏感信息；不要向客户索取密码或验证码。
- 涉及金额争议、扣款异常时，以客户账户内实际展示的记录为准；回复「转人工」由人工客服核对。
- 【待业务确认：账单 / 交易记录的入口菜单层级、可查询时间范围、是否支持导出、
  导出文件格式。确认前不得向客户输出任何具体页面名称或按钮位置。】

## 账户与登录

- 客服无法仅凭聊天确认客户真实身份，也无法查看或提供账号密码。
- 密码找回、账号资料变更请通过商城官方账号渠道办理；回复「转人工」可获取协助说明。
- 不要向客户索取验证码、支付密码或完整银行卡号。

## 订单状态与物流进度

- 发货后物流单号会同步到订单页面，通常 24 小时内可查询到揽收记录。
- 退款进度可在订单详情页查看，客服不能人工加速到账。
- 客服不能代客户修改收货地址、取消订单或变更商品规格。

## 发票

- 下单时可在备注中填写发票抬头与税号；订单完成后 3 个工作日内开具并发送至预留邮箱。
- 暂不支持增值税专用发票。
- 需要发票文件、补开或换开时，回复「转人工」由人工客服处理。

## 优惠与会员

- 商品价格随活动浮动，下单价格即成交价格；是否支持价保以商品页说明为准。
- 优惠券、满减的适用范围以下单结算页展示为准。

## 人工客服时间

- 在线人工客服服务时间为每日 9:00 至 18:00。
- 非服务时段可留言，工单会在下一个服务时段内处理。
- 需要人工协助时回复「转人工」；本系统不承诺具体响应时长，高峰期可能需要等待。
