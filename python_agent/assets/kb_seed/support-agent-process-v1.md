# 客服通用流程（演示参考）

来源：`support-agent/data/faq/process-playbook-v1.md`，本文件是为主项目整理的通用流程摘要。
类型：通用流程说明；不属于任何租户的商家政策，不是承诺。

- 退货咨询：先收集订单号与退货原因；订单归属、商品情况与商家已发布政策需要核验后，才能判断处理方式。
- 订单查询：仅在客户身份、会话与订单归属核验通过后展示本人订单信息；核验失败时不推测订单状态。
- 退款与支付：当前客服 Agent 不执行退款或支付操作，相关诉求可转人工。实际开放需要真实业务接口、归属核验与独立审批。
- 转人工：用户明确要求时创建工单，之后由人工客服接管；不得承诺等待时长或已经处理完成。

上述内容只解释咨询流程，不构成退换货资格、到账时间、运费、金额等店铺条款。
