# 简历可写范围

建议只在能展示本仓改动和验收记录时使用下述表述：

> 在现有多租户客服项目中整合电商客服 Agent 的通用 FAQ 流程与回答边界：通过 Go 到 Python 的内部身份校验、租户知识库索引和来源标识，让前端 FAQ 回答可核验；将缺少客户归属证明的订单查询改为明确拒答，并关闭公开演示订单查询；修正转人工按钮与工单流程，实测前端建单、后台查询和会话消息落库。

可以展示：`docs/MERGE_GOAL.md`、`docs/MERGE_ACCEPTANCE.md`、对应代码差异、测试输出及 `frontend-acceptance.png`。

不应写成已经完成：真实订单查询、退款/支付业务闭环、客户级身份认证、公开商家政策 RAG 评测、原项目整体 SaaS 架构或未经测量的性能提升。
