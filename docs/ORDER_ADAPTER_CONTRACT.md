# 真实订单接入契约（待业务系统提供）

## 当前状态（已实现：虚构数据演示链路）

- `/api/agent/order`（Go 内部只读入口，`X-Internal-Token` 保护）：已从 fail-closed 503 改为**真实查表 + 归属校验**，使用 `orders` 表演示数据（2 条，归属 `t_demo:buyer1`）。
- 旧公开 `/api/business/order` 仍返回 410。
- 客户身份来自**服务端签发的客户会话**：`/api/auth/customer-token`（演示模式）签发 `kind=customer` 短期令牌（2h）并落库 `customer_sessions`；`UserAuth` 以会话记录注入 `tenant_id/customer_id/thread_id`，浏览器传入的 `user_id` 不再作为身份来源。
- 订单查询三条件限定：`WHERE tenant_id=? AND customer_id=? AND order_id=?`；`customer_id` 由请求 `thread_id` 反查会话记录得到。**订单不存在与不属于该客户返回完全相同的提示**，不暴露订单存在性。
- 令牌类型边界（P0）：管理端验签 `VerifyTokenFull` 对任何非空 `kind` 一律拒绝（客户令牌进管理端、刷新转换成管理令牌两条路径均已封死并有回归测试）；`/api/auth/refresh` 只刷新管理/子账号令牌并保留 `uid`；`UserAuth` 只接受 `kind=customer` 令牌且核对服务端会话记录。

## 业务码语义与转人工边界（2026-10-19）

Agent 侧把业务码映射为结果码决定是否转人工，**不再匹配展示文案**：

| 业务码 | 结果码 | 转人工 | 说明 |
|---|---|---|---|
| `0` | `OK` | 否 | 归属校验通过，返回订单字段 |
| `401` | `UNAUTHENTICATED` | 否 | 访客/未登录，提示登录 |
| `404` | `NOT_FOUND` | 否 | 单号不存在**或**非本账号（服务端合并，防枚举），提示用户核对单号 |
| `403` | `FORBIDDEN` | 是 | 归属校验不通过，需要人工核实 |
| `5xx`/超时 | `UNAVAILABLE` | 是 | 业务系统不可用 |
| Token/租户上下文缺失 | `UNVERIFIED` | 是 | 部署配置问题，需要人工 |

约束：404 的展示文案不得断言订单是否存在（「没有查到订单 xxx」而非「订单不存在」），也不得附带「请转人工客服」字样——自动转人工由结果码决定，不由文案决定。

## 接入前必须完成

可信宿主在服务端验证登录状态后签发短期令牌，令牌至少绑定 `tenant_id`、不可变 `customer_id`、`session_id` 和有效期。Go 以令牌主体为准创建或读取会话，不能从浏览器传来的 `user_id` 或订单号推断归属。HTTP 历史、WebSocket、工单与订单查询必须共用该校验。现有租户级 `app_key` 令牌不足以证明访客身份。

> 演示登录（`demo_customer_login`）的边界：它复用的演示客户凭证只能证明"服务端签发了这个选择"，不能证明访问者就是该客户本人；只适合严格隔离的虚构数据演示。真实接入必须关闭该开关，把凭证校验替换为商家现有登录态校验，会话/归属/查询链路不变。

## 只读订单适配器要求

接受 `(tenant_id, customer_id, order_id, trace_id)`，从真实业务系统返回已核验的订单状态与可展示字段。必须由业务系统或 Go 适配器在一次受控查询中同时校验租户和客户归属；跨租户、非本人和不存在的订单对用户统一返回"未找到可查询订单"，不泄露是否存在。不得以客户姓名、手机号末位或 LLM 推断作为归属证明。超时、业务系统错误、缺少身份、缺少归属字段一律拒绝返回订单详情，并留下 trace（避免记录完整 PII）。

## 验收至少覆盖

本人订单成功、同租户他人订单、跨租户订单、无效/过期/已吊销令牌、未知类型令牌（管理端与客户入口均拒）、订单不存在、业务接口超时、会话重放与重试；前端页面、Go、Python Agent 和真实业务 API 的结果要一致。

已落地证据：

- 单元/中间件层（fake 注入，`go test ./...`）：入口身份校验、本人命中、同租户另一客户（与"不存在"字节级同提示）、无会话/伪造/过期 fail-closed、客户令牌过 `AdminAuth` 被拒、管理/子账号令牌过 `UserAuth` 被拒、未知类型双入口被拒、子账号刷新 `uid` 保留、客户令牌刷新被拒、演示凭证分离与白名单、`thread_id` 同秒不碰撞
- 真实 MySQL 层（`go test -tags=integration`，需 `CS_TEST_MYSQL_DSN` 且库名含 `test`）：六场景归属验收 + `UserAuth` 真实会话查询，只写入/删除 `ITEST-` 前缀数据
